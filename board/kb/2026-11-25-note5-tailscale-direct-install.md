# 앱을 설치할 수 없는 오래된 폰(안드로이드 7.0)도 집 밖에서 접속되는 작은 서버로 — Tailscale 직접 설치 기록

> 사진 13장이 들어 있는 전체 매뉴얼은 아래 링크에서 엽니다.

**[매뉴얼 열기 (사진 포함)](/manuals/note5-tailscale-direct-install.html)**

## 이 글이 다루는 것

- 안드로이드 8 미만이라 Tailscale **앱이 설치되지 않는** 폰에서 Tailscale을 쓰는 방법
- 집 밖에서 스마트폰으로 이 폰의 홈페이지(게시판)를 여는 방법
- 폰이 꺼졌다 켜져도 **저절로 다시 연결되게** 하는 방법
- 막혔던 일과 해결 방법(시행착오 모음)

## 먼저 결론

**앱 대신 Tailscale 프로그램을 Termux에서 직접 실행**하는 방법으로 해결했습니다. 내 Tailscale 기기끼리만 연결되며, 인터넷에 누구나 접속하게 공개한 것이 아닙니다.

## 확인한 것과 확인하지 못한 것

- **확인됨:** 집 밖(모바일 데이터)에서 접속, 재부팅 뒤 자동 복구, 처음부터 다시 설치, 약 16시간 연속 가동(끊김 없음)
- **미확인:** 며칠~몇 주 이상의 안정성, 벽 충전기 상태의 배터리·열, 다른 기종에서의 재현, 여러 사람의 동시 접속

이 글은 "이렇게 하면 된다"는 보증이 아니라 "이렇게 해 보니 여기까지 됐다"는 기록입니다.
