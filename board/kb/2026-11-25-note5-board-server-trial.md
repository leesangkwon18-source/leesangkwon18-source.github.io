# 쓰지 않는 오래된 스마트폰으로 작은 게시판 서버 만들기 — 갤럭시 노트5 시험 기록

> 사진 10장이 들어 있는 전체 매뉴얼은 아래 링크에서 엽니다.

**[매뉴얼 열기 (사진 포함)](/manuals/note5-board-server-manual.html)**

## 이 글이 다루는 것

- 쓰지 않는 폰에 **Termux**라는 앱을 깔아 작은 서버를 돌리는 과정
- 폰 화면이 작고 글자 입력이 힘들 때 **컴퓨터가 대신 조작**하는 방법
- 게시판이 실제로 **돌아가는지 확인한 방법과 결과**
- 폰이 꺼졌다 켜져도 **게시판이 저절로 켜지게** 하는 방법
- 막혔던 일과 해결 방법

## 먼저 결론

이 폰에서 게시판은 잘 돌아갔습니다. 다만 **오래 켜 두었을 때의 안정성, 아주 큰 파일 올리기, 여러 사람이 동시에 쓰기는 이 글을 쓸 때는 시험하지 못했습니다.** 이 글은 2026년 11월 24일의 시험 기록입니다. 이후 Tailscale을 직접 설치해 집 밖에서 접속하는 방법은 별도 글(Tailscale 직접 설치 기록)에 있습니다.
