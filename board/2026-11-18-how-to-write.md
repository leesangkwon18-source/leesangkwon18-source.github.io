# 게시판에 글 올리는 방법

이 글은 게시판이 잘 동작하는지 시험하는 **샘플 글**이면서, 앞으로 글을 올릴 때 보는 **사용법**입니다. 필요 없어지면 삭제해도 됩니다.

## 한눈에 보기

| 하고 싶은 일 | 방법 |
| --- | --- |
| 글 올리기 | GitHub에서 **알맞은 자료실 폴더**에 `.md` 파일 하나를 올립니다 |
| 글 고치기 | GitHub에서 그 파일을 열고 연필 아이콘을 누릅니다 |
| 글 지우기 | GitHub에서 그 파일을 열고 삭제합니다 (삭제 주소를 써도 됩니다) |
| 목록 | 따로 만들 필요 없이 **자료실마다 자동**으로 날짜순으로 나타납니다 |

## 자료실은 네 곳입니다

연구 분야와 똑같이 네 가지로 나뉩니다. 글을 올릴 **폴더**가 곧 자료실입니다.

| 자료실 | 올릴 폴더 |
| --- | --- |
| 01 경찰견 전문 지식 자료실 | `board/k9` |
| 02 인공지능 연구 자료실 | `board/ai` |
| 03 멀티 AI 협업 시스템 연구자료실 | `board/multi-ai` |
| 04 연구 지식창고 자료실 | `board/kb` |

`board` 바로 아래에 올린 글은 어느 자료실에도 속하지 않고 **게시판 안내**로만 보입니다. 연구 자료는 반드시 위 네 폴더 중 하나에 올리세요.

## 1. 글 파일 만들기

파일 이름은 **날짜로 시작하는 영어 이름**으로 짓습니다.

```text
2026-11-20-police-dog-training-notes.md
```

- 앞의 `2026-11-20`이 목록에 날짜로 표시되고, 날짜가 클수록 위에 보입니다.
- 한글 이름도 되지만, 주소가 길고 보기 어려워져서 영어 이름을 권합니다.

파일의 **첫 줄**은 제목입니다. `#` 하나와 공백 뒤에 제목을 씁니다.

```markdown
# 경찰견 후각 훈련 정리

여기부터 본문을 마크다운으로 씁니다.
```

## 2. 올리기

1. GitHub 저장소에서 해당 자료실 폴더(예: `board/k9`)로 들어갑니다.
2. **Add file → Upload files**를 누르고 `.md` 파일을 끌어다 놓습니다. (또는 **Create new file**로 화면에서 바로 써도 됩니다.)
3. **Commit changes**를 누릅니다.
4. 1~3분 뒤에 그 자료실 목록과 게시판 첫 화면의 자료 수에 나타납니다. 안 보이면 **Ctrl+F5**로 새로고침하세요.

## 3. 꼭 지킬 것

> 공개 사이트입니다. **비밀번호, 토큰, 서버 주소, 개인정보, 비공개 업무 자료**는 글에 쓰지 않습니다. 올리기 전에 한 번 더 확인하세요.

- 중괄호를 연속으로 두 번 쓰는 표기나 퍼센트 기호가 붙은 중괄호는 변환을 깨뜨릴 수 있습니다. 그런 명령을 써야 하면 앞뒤를 `raw` 표시로 감싸야 하니, 올리기 전에 저에게 먼저 보여 주세요.
- 꺾쇠로 감싼 자리표시자는 반드시 `` `<이름>` ``처럼 **백틱(`)으로 감싸서** 쓰세요. 감싸지 않으면 화면에서 사라질 수 있습니다.
- 첫 줄 제목이 화면에 나오지 않으면, 파일 맨 위에 제목 머리말을 넣는 방법도 있습니다. 이때는 저에게 알려 주세요.
- 사진은 지금 바로 쓰지 말고, 필요하면 `images` 폴더에 먼저 올린 뒤 연결하는 방법을 상의하세요.
