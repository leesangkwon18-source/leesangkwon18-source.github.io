# Hermes 운영 매뉴얼 목차 — 어떤 순서로 읽을까요

Claude와 GPT 같은 AI를 연결해 함께 일하게 하는 Hermes Agent 환경을 만들고, 운영하고, 백업하는 방법을 정리했습니다. 초보자용 매뉴얼 5종이며, 2026년 10~11월 실제 운영 기록을 기준으로 합니다. 모든 매뉴얼은 **확인된 것**과 **확인하지 못한 것**을 구분해서 적었습니다.

## 매뉴얼 5종

### 1. WSL에서 Hermes Agent 시작하기

Windows PC · 초보자용 따라 하기 · 처음이면 2~3시간. Windows 안의 리눅스(WSL Ubuntu)에 Hermes Agent를 Docker 상자 안에서 설치하고, Claude(총괄)와 GPT(검증관)를 구독 로그인으로 연결해 첫 협업까지 해 보는 매뉴얼입니다.

알아 둘 한계: 기존 파일 변경 시 승인창을 강제하는 장치는 미구현이고, 재부팅 후 Docker 자동 시작은 미확인입니다. → [글 열기](/board/2026-11-16-wsl-getting-started.html)

### 2. 일반협업팀 구축·운영·백업 매뉴얼

Ubuntu 서버 · 구축·운영 · 기존 환경 보존. 한 대의 서버에서 기존 Hermes 환경을 보존한 채 신규 협업 환경(바코1 팀장, 지코1 독립 검증)을 만드는 방법입니다.

알아 둘 한계: 재부팅 후 자동 시작, 장애 자동 복구, 백업 파일로 실제 복원은 미검증입니다. → [글 열기](/board/2026-11-16-general-team-setup.html)

### 3. 갤럭시 노트9로 만드는 독립 Hermes Agent 서버

안드로이드 폰 · 설치·원격 접속·복구. 안드로이드 폰(Termux와 PRoot Ubuntu)에 독립 Hermes 서버를 두고, USB·ADB 포트 전달과 SSH 역방향 터널로 원격 접속하고 점검·복구하는 방법입니다.

알아 둘 한계: 실제로 성공한 절차와 미검증 항목을 구분해 적었습니다. 처음부터의 완전 재설치 보증서는 아닙니다. → [글 열기](/board/2026-11-16-note9-hermes-manual.html)

### 4. AI 협업 운영 매뉴얼

협업 규칙 · 환경과 무관하게 읽기. 바코(Claude)와 지코(GPT)가 독립 분석하고 서로 검증하도록 운영하는 방법입니다.

알아 둘 한계: 호출 상한 초과·승인 거부 시험, 비용 측정, 단일 모델 기준선과의 비교는 하지 않았습니다. → [글 열기](/board/2026-11-16-ai-collaboration.html)

### 5. Hermes 백업·복원 매뉴얼

공통 · 서버와 폰 · 백업을 만들고 검증하는 법. 백업을 만들고(암호화·비암호화), SQLite를 안전하게 복사하고, 압축·목록·해시로 단계별 검증하고, PC에 이중 보관하는 방법입니다.

알아 둘 한계: 백업은 만들고 해시로 검증했지만 실제 복원은 한 번도 하지 않았습니다. 복원 절차는 계획입니다. → [글 열기](/board/2026-11-16-backup-restore.html)

## 모든 매뉴얼에 공통인 약속

- 확인된 것과 확인하지 못한 것을 구분해 적었습니다. 확인하지 못한 항목은 각 매뉴얼 마지막 부분에 모아 두었습니다.
- 비밀값(토큰, 키, 비밀번호)은 싣지 않았습니다. 여러분도 채팅·캡처·공개 저장소에 올리지 마세요.
- 서버 주소, 계정, 키 파일 이름 같은 개인 환경 값은 `<…>` 표시로 바꿨습니다. 자기 값으로 바꿔 쓰세요.
- 명령은 한 번에 하나씩, 어느 장비(메인 PC / 서버 / 폰)에서 치는지 확인하고 결과를 본 뒤 다음으로 갑니다.
- 기존 환경은 보존하고, 변경 전에는 백업하고, 실행 전에는 승인을 받습니다.
- "작성자 권장"으로 표시한 부분은 운영 기록이 아니라 일반적인 권고입니다.
- 시간이 지나면 달라질 수 있습니다. 프로그램 버전, 모델 이름, 화면 문구는 기록 당시의 값입니다. 실제 화면과 다르면 다음 단계로 넘어가지 말고 각 매뉴얼의 오류 대응 부분을 먼저 보세요.
