쓰지 않는 오래된 스마트폰으로 작은 게시판 서버 만들기 — 갤럭시 노트5 시험 기록

이 글은 2015년에 나온 스마트폰(갤럭시 노트5, 안드로이드 7.0)에 작은 홈페이지와 게시판을 올려 보고 시험한 2026년 11월 24일의 기록을 초보자용으로 정리한 것입니다.

먼저 결론입니다. 이 폰에서 게시판은 잘 돌아갔습니다. 하지만 오래 켜 두었을 때의 안정성, 아주 큰 파일 올리기, 여러 사람이 동시에 쓰기는 아직 시험하지 못했습니다. 그래서 이 글은 "이렇게 하면 된다"는 보증이 아니라 "이렇게 해 보니 여기까지 됐다"는 기록입니다. 확인한 것과 확인하지 못한 것을 구분해서 적었습니다.

0. 먼저 읽기

이 글이 다루는 것

  • 쓰지 않는 폰에 Termux라는 앱을 깔아 작은 서버를 돌리는 과정
  • 폰 화면이 작고 글자 입력이 힘들 때 컴퓨터가 대신 조작하는 방법
  • 게시판이 실제로 돌아가는지 확인한 방법과 결과
  • 폰이 꺼졌다 켜져도 게시판이 저절로 켜지게 하는 방법
  • 막혔던 일과 해결 방법

이 글이 다루지 않는 것

  • 게시판 프로그램을 만드는 방법(이미 만들어 둔 프로그램을 올려서 시험했습니다)
  • 인터넷에 공개하는 방법(이 시험은 집 안 와이파이 안에서만 했습니다)
  • 폰을 영구적으로 서버로 쓰는 것이 안전한지에 대한 최종 판단

안전 먼저: 오래된 폰의 배터리

  • 배터리가 부풀었거나, 뜨겁거나, 이상한 냄새가 나면 켜지도 충전하지도 마세요. 2015년 제품은 배터리를 빼낼 수 없어서 특히 조심해야 합니다.
  • 충전할 때는 이불이나 종이 위에 두지 말고, 처음에는 옆에서 지켜보세요.
  • 이 시험에서는 배터리 상태가 "양호"였고 온도는 약 23~26도로 변화가 없었습니다. 하지만 오래 켜 둔 결과는 모릅니다.

1. 준비물

준비물 설명
쓰지 않는 안드로이드 폰 이 시험은 갤럭시 노트5(안드로이드 7.0)로 했습니다
데이터가 통하는 USB 선 충전만 되는 선은 안 됩니다(아래 "막혔던 일" 참고)
컴퓨터 폰을 대신 조작할 서버용 또는 일반 컴퓨터
집 와이파이 폰과 접속할 기기를 같은 와이파이에 연결해야 합니다

폰 상태 먼저 확인하기

폰에서 설정 → 휴대전화 정보 → 소프트웨어 정보를 열어 안드로이드 버전을 봅니다. Termux는 안드로이드 7.0 이상이 필요합니다. 이 시험의 폰은 7.0이어서 겨우 조건에 맞았습니다.

항목 이 시험의 폰
안드로이드 7.0
보안 패치 날짜 2018년 8월(아주 오래됨)
저장공간 128GB 중 약 105GB 남음
메모리(RAM) 약 3.75GB

보안 패치가 2018년이라는 것은 그 뒤로 보안 업데이트가 없다는 뜻입니다. 그래서 이런 폰은 인터넷에 바로 공개하는 서버로는 쓰지 않는 것이 좋습니다. 집 안에서만 쓰는 시험용·보조용이 알맞습니다.

2. 컴퓨터로 폰 조작하기 (글자 입력이 힘들 때)

폰 화면이 작아서 글자를 입력하기 힘들다면, 컴퓨터가 폰에 명령을 보내서 대신 조작하게 할 수 있습니다.

2-1. USB로 연결하고 허용하기

  1. 폰을 컴퓨터에 USB 선으로 연결합니다.
  2. 폰 화면에 "USB 디버깅을 허용하시겠습니까?" 창이 뜨면 "이 컴퓨터에서 항상 허용"에 체크하고 확인을 누릅니다.
  3. "확인"만 누르면 그때 한 번만 허용됩니다. "항상 허용"을 체크해야 다음에도 저절로 연결됩니다.
  4. 이 시험에서는 허용 창이 바로 떴습니다. 이 창이 안 뜨는 폰은 보통 설정 → 개발자 옵션에서 USB 디버깅을 켜야 하는데, 이 방법은 이 시험에서 직접 확인하지 않았습니다.

2-2. 화면 캡처로 폰을 눈으로 확인하기

컴퓨터에서 "지금 폰 화면을 사진으로 찍어라"라고 명령하면, 폰을 만지지 않고도 폰 화면을 볼 수 있습니다.

  • 찍힌 사진은 폰 사진첩에 저장되지 않고 컴퓨터에만 생깁니다.
  • 설치가 잘 됐는지, 오류가 났는지, 화면이 꺼졌는지를 확인할 때 씁니다.

주의 1: 폰 화면이 꺼져 있으면 캡처가 까맣게 나옵니다. 고장이 아니라 화면이 꺼져 있는 것입니다. 먼저 화면을 켜야 합니다.

주의 2: 잠금 화면 캡처에는 계정 알림이 보일 수 있습니다. 그 사진을 공개하기 전에 이메일 같은 개인 정보는 반드시 가려야 합니다. 화면이 잠겨 있으면 밀어서 풀어야 앱이 보입니다. (이 글에서는 잠금 화면 사진을 싣지 않았습니다.)

2-3. 소프트웨어 업데이트 알림은 미루기

오래된 폰은 "소프트웨어 업데이트" 알림이 뜹니다. 이 시험에서는 "나중에"로 미뤘습니다. 업데이트는 오래 걸리고, 도중에 전원이 꺼지면 폰이 켜지지 않을 위험이 있기 때문입니다.

3. Termux 설치하기

Termux는 안드로이드 폰 안에서 리눅스 명령을 쓸 수 있게 해 주는 앱입니다. 서버 프로그램을 폰에서 돌리는 바탕이 됩니다.

3-1. 반드시 F-Droid 버전을 받기

  • 구글 플레이 버전은 오래돼서 쓰면 안 됩니다. 코드가 달라서 서로 맞지 않습니다.
  • F-Droid 사이트(f-droid.org)의 Termux 페이지에서 받습니다. 이 시험에서는 0.118.3 버전(파일 약 108MB) 을 받았고, 페이지에 "안드로이드 7.0 이상 필요"라고 적혀 있었습니다.
  • 파일 이름은 com.termux_1002.apk였습니다.

3-2. 컴퓨터에서 받아서 폰에 설치하기

폰 화면이 작아서 이 시험에서는 컴퓨터에서 파일을 받고, 컴퓨터가 폰에 설치했습니다.

  1. 컴퓨터에서 F-Droid 공식 주소로 파일을 받습니다.
  2. 받은 파일의 크기와 형식을 확인합니다(F-Droid가 적은 크기와 맞는지).
  3. 컴퓨터가 폰에 설치합니다. 설치가 끝나면 "Success"라는 글자가 나옵니다.
  4. 폰의 앱 목록에 Termux가 생깁니다.

참고: 파일이 중간에 바뀌지 않았는지 파일 지문(해시값) 이 보내기 전과 후가 같은지도 확인했습니다. F-Droid 페이지에는 지문 값이 따로 적혀 있지 않아, 서명 파일은 확인하지 않았습니다. 공식 주소에서 받은 것으로 신뢰하는 방식입니다.

3-3. 처음 열어 보기

Termux를 처음 열면 기본 환경이 저절로 내려받아집니다(와이파이 필요). 끝나면 아래와 같은 환영 화면과 명령 입력줄(~ $)이 나옵니다.

4. 파이썬 설치하기

폰의 CPU 종류와 파이썬이 있는지 먼저 확인했습니다. 폰은 aarch64(64비트) 이고, 파이썬은 처음에는 없었습니다.

설치 명령은 한 줄입니다.

pkg install -y python

설치하는 동안 폰의 배터리와 온도를 확인했는데 변화가 없었습니다. 설치가 끝나면 화면 끝에 빨간 오류 글자가 보이지만, 이것은 마지막 정리 단계의 경고였고 설치와 실행에는 지장이 없었습니다.(정확한 원인은 확인하지 못했습니다.)

그다음 파이썬이 정상인지 확인했습니다.

python3 --version

결과는 파이썬 3.14.10 이었습니다. 게시판은 비밀번호를 암호로 바꿔 저장하는 기능(scrypt) 을 쓰는데, 이 기능이 폰에서도 되는지 따로 확인했고 정상으로 작동했습니다.

5. 게시판 프로그램을 폰에서 돌려 보기

5-1. 프로그램 파일을 폰으로 가져오기

게시판 프로그램은 파이썬 기본 기능만 써서 따로 설치할 부품이 없습니다. 이 시험에서는 컴퓨터와 폰을 USB 선 안에서만 이어서 폰이 파일 4개(프로그램, 홈페이지, 스타일 파일)를 가져가게 했고, 집 와이파이에는 열지 않았습니다. 가져온 뒤 파일 지문이 원본과 같은지 확인했습니다.

5-2. 폰 안에서 시험하기

가짜 회원과 가짜 글만 써서 점검했습니다. 실제 회원 정보는 쓰지 않았습니다.

1차 점검(기본 기능): 홈페이지 열림, 자유게시판 열림, 없는 주소는 404 안내, 가짜 회원 가입, 승인 전에는 로그인이 막힘, 관리자 승인 뒤 로그인, 글쓰기, 목록 표시, 틀린 비밀번호 거부, 글이 파일로 저장됨, 회원 파일은 본인만 읽게 설정됨, 비밀번호가 글자 그대로 저장되지 않음. 전부 통과했고 서버가 쓴 메모리는 약 40MB였습니다.

2차 점검(더 많은 기능): 댓글, 링크가 새 탭으로 열림, 남의 글·댓글은 못 고침, 관리자는 고칠 수 있음, 파일 첨부(일반 회원은 3개까지·종류 제한, 관리자는 HTML도 가능), 비밀번호 변경, 글 삭제(휴지통으로 이동), 서버를 껐다 켠 뒤에도 글과 로그인 유지. 27개가 모두 통과, 실패 0개였습니다.

5-3. 컴퓨터 브라우저로 직접 써 보기

컴퓨터 → 서버용 컴퓨터 → USB 선 → 폰 순서로 임시 길을 만들어, 컴퓨터의 인터넷 창에서 폰의 게시판을 열었습니다. 직접 가입하고 글을 쓰고 파일을 붙이는 것까지 확인했습니다.

6. 와이파이로 다른 기기에서 접속하기

6-1. 같은 와이파이여야 합니다

폰의 와이파이 주소는 집 공유기 안쪽 주소(192로 시작하는 숫자)입니다. 같은 와이파이에 연결된 기기에서만 열립니다.

이 시험에서는 컴퓨터에서 직접 접속이 안 됐습니다. 컴퓨터와 폰이 서로 다른 네트워크에 있었기 때문입니다. 반면 울트라 폰을 노트5와 같은 와이파이에 연결하니 바로 열렸습니다.

교훈: 접속 시험을 하기 전에, 접속할 기기와 서버 폰이 같은 와이파이인지 먼저 확인하세요.

6-2. USB를 뽑고 화면이 꺼져도 살아 있게 하기

USB를 뽑으면 컴퓨터는 폰을 볼 수도 조작할 수도 없습니다. 그래서 뽑기 전에 필요한 설정을 모두 끝내야 합니다. 이 시험에서 한 설정은 다음과 같습니다.

설정 하는 일
배터리 최적화에서 Termux 제외 폰이 절전하려고 Termux를 멈추는 것을 막음
Termux "깨어 있음 유지" 화면이 꺼져도 폰이 잠들지 않게 함

Termux 안에서 이 한 줄을 입력하면 깨어 있음 유지가 켜집니다.

termux-wake-lock

그다음 USB를 뽑고 벽 충전기를 꽂은 뒤 폰 화면을 끄고 10분 기다렸습니다. 다른 기기에서 새로 고침하니 그대로 열렸고 글도 올라갔습니다.

주의: 서버가 실행 중이면 같은 와이파이의 다른 기기도 접속을 시도할 수 있습니다. 이 시험은 가짜 데이터뿐이었지만, 실제 자료를 올리기 전에는 누가 접속할 수 있는지 다시 판단해야 합니다.

7. 폰이 꺼졌다 켜져도 게시판이 저절로 켜지게 하기

지금까지는 사람이 서버를 한 번 켜 둔 상태였습니다. 폰이 재시작되거나 배터리가 다 닳아 꺼졌다 켜지면 서버는 꺼진 채로 남습니다. 그래서 저절로 켜지게 만들었습니다.

7-1. Termux:Boot 설치

  • F-Droid에서 Termux:Boot를 받습니다. 이 시험에서는 0.8.1 버전, 파일 약 25KB였고 "안드로이드 5.0 이상 필요"라고 적혀 있었습니다.
  • 설치한 뒤 앱을 한 번 열어야 켜질 때 실행이 허용됩니다. "Start the Termux:Boot app once…"라고 적힌 설명 화면이 나오면 된 것입니다.

7-2. 시작 스크립트 만들기

~/.termux/boot/ 폴더에 다음 5줄짜리 파일(start-board.sh)을 만들었습니다.

#!/data/data/com.termux/files/usr/bin/sh
termux-wake-lock
sleep 20
cd ~/k9test
K9_HOST=0.0.0.0 K9_PORT=8080 nohup python3 app.py > server.log 2>&1 &
줄 하는 일
1 이 파일이 Termux 스크립트라는 표시
2 깨어 있음 유지
3 와이파이가 붙을 때까지 20초 기다림
4 게시판 프로그램이 있는 폴더로 이동
5 게시판 프로그램을 켬

파일 이름은 마음대로 정해도 됩니다(이 글에서는 start-board.sh라고 부르겠습니다). 파일에 실행 권한을 주어야 합니다.

chmod 700 ~/.termux/boot/start-board.sh

7-3. 재부팅 시험

폰을 껐다 켰더니 약 10초 만에 안드로이드가 켜지고 와이파이 주소를 받았으며, 그 뒤 게시판이 저절로 떠서 정상으로 응답했습니다. 깨어 있음 유지도 저절로 다시 걸렸습니다. 재부팅 뒤에도 컴퓨터의 USB 디버깅 허용은 유지됐습니다.

8. 막혔던 일과 해결 (꼭 읽어 보세요)

증상 원인 해결
컴퓨터가 폰을 못 찾음 폰을 엉뚱한 컴퓨터에 꽂았음 폰을 꽂아야 하는 컴퓨터를 확인
폰이 3~4초 붙었다 끊기기를 반복(4분에 15번) USB 선 접촉 불량으로 추정(확정 못 함) 데이터가 통하는 다른 선으로 교체하니 안정됨. 충전은 되는데 데이터는 안 통하는 선이 있습니다
컴퓨터가 폰을 "허용 안 됨"으로 봄 USB 디버깅 허용을 "한 번만" 눌렀음 "이 컴퓨터에서 항상 허용"을 체크하고 확인
화면 캡처가 까맣게 나옴 폰 화면이 꺼져 있음(자동 절전) 컴퓨터가 화면을 켜는 명령을 보냄
화면을 켜도 앱이 안 보임 잠금 화면 밀어서 잠금 해제
컴퓨터가 입력한 명령에 한글이 안 들어감 대신 입력 방식의 한계 명령은 영문만 씀
시작 스크립트의 첫 줄(#!)이 빠짐 특수 기호가 걸러짐 만든 뒤 파일 내용을 열어서 반드시 확인하고 다시 넣음
서버를 app.py로 찾았는데 안 보임 안드로이드 프로세스 목록에는 이름만 나옴 python3로 찾음
컴퓨터에서 와이파이 주소로 접속 안 됨 컴퓨터와 폰이 다른 네트워크 같은 와이파이의 다른 기기(스마트폰)로 시험

9. 메모리와 저장공간은 충분한가

항목 서버용 컴퓨터 노트5
메모리 총량 7.3GB 3.75GB
쓸 수 있는 메모리 약 5.6GB 약 1.9GB (캐시 포함)
저장공간 233GB 중 188GB 남음 114GB 중 105GB 남음
게시판이 쓰는 메모리 약 46MB 약 22MB
  • 게시판만 놓고 보면 메모리와 저장공간 모두 충분합니다. 글은 텍스트라서 1만 건이 약 50MB 정도로 계산됩니다.
  • 용량이 커지는 쪽은 첨부 파일입니다. 큰 자료는 구글 드라이브 링크로 올리는 것이 좋습니다.
  • 파일을 지운다고 메모리가 늘지 않습니다. 저장공간과 메모리는 다릅니다. 메모리는 앱을 멈춰야 늘 수 있습니다.
  • 백그라운드 앱 9개를 강제로 종료해 봤지만 쓸 수 있는 메모리는 거의 그대로였습니다. 그 앱들은 이미 캐시로 잡혀 있어 안드로이드가 필요할 때 알아서 비우기 때문입니다.

10. 확인하지 못한 것 (그래서 아직 보증할 수 없는 것)

  • 하루 이상 켜 두었을 때의 안정성과 배터리 변화
  • 200MB 같은 큰 파일을 폰에서 올릴 때의 메모리 사용량
  • 여러 사람이 동시에 접속할 때의 속도
  • 충전 겸용 랜 어댑터가 이 폰의 단자에 맞는지(유선으로 바꾸려는 경우)
  • 폰의 USB 디버깅을 처음 켜는 방법(이 시험에서는 허용 창이 바로 떴음)
  • 인터넷 공개: 이 시험은 집 안 와이파이에서만 했습니다.

11. 시험 뒤 정리하기

시험이 끝나면 켜 둔 설정을 되돌립니다.

  • USB 디버깅 끄기
  • 충전 중 화면 켜짐 유지, Termux 절전 제외, 깨어 있음 유지 되돌리기
  • 서버를 집 와이파이에 열어 둔 채 두지 않기(필요 없으면 끄기)
  • 시험용 폴더와 가짜 회원 정보 지우기
  • 폰을 안 쓸 때는 Termux 앱을 지우면 설치한 파이썬 등이 함께 사라집니다.

12. 한 줄 정리

오래된 폰으로도 작은 게시판은 돌릴 수 있습니다. 다만 데이터가 통하는 선, 같은 와이파이, 허용 설정, 시작 스크립트 확인이 핵심이고, 오래 켜 둔 안정성은 아직 모릅니다. 인터넷 공개나 실제 회원 정보는 올리기 전에 반드시 다시 판단하세요.
